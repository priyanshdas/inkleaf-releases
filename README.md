# Inkleaf downloads

This is where Inkleaf's finished builds are published. The source code,
issues and everything else live in the main repository:
**[priyanshdas/inkleaf](https://github.com/priyanshdas/inkleaf)**.

Inkleaf is a free, open-source PDF editor that works offline. Edit the text
that's already in a PDF, sign, fill forms, redact, convert, clean up scans
and rearrange pages, with no account and nothing uploaded unless you choose
to send a file.

## Download

Get the newest version from **[Releases › Latest](https://github.com/priyanshdas/inkleaf-releases/releases/latest)**,
or from the [Microsoft Store](https://apps.microsoft.com/detail/9NKC5ZQ6P2JR)
on Windows.

| You're on | Download | Notes |
| --- | --- | --- |
| Windows | [Inkleaf-Setup.exe](https://github.com/priyanshdas/inkleaf-releases/releases/latest/download/Inkleaf-Setup.exe) | Installs Inkleaf and keeps it up to date. |
| Windows, no install | [Inkleaf-Portable.exe](https://github.com/priyanshdas/inkleaf-releases/releases/latest/download/Inkleaf-Portable.exe) | Runs from any folder or a USB stick. Doesn't update itself. |
| Linux, any distribution | AppImage for [x64](https://github.com/priyanshdas/inkleaf-releases/releases/latest/download/Inkleaf-linux-x86_64.AppImage) or [arm64](https://github.com/priyanshdas/inkleaf-releases/releases/latest/download/Inkleaf-linux-arm64.AppImage) | Make it executable (`chmod +x`), then open it. |
| Debian, Ubuntu, Mint | .deb for [x64](https://github.com/priyanshdas/inkleaf-releases/releases/latest/download/Inkleaf-linux-amd64.deb) or [arm64](https://github.com/priyanshdas/inkleaf-releases/releases/latest/download/Inkleaf-linux-arm64.deb) | `sudo apt install ./Inkleaf-linux-amd64.deb` |
| Fedora, openSUSE | [.rpm](https://github.com/priyanshdas/inkleaf-releases/releases/latest/download/Inkleaf-linux-x86_64.rpm) | x64 only. |
| Android | `Inkleaf-Android.apk` on the release page | Android 7.0 or newer. Allow installs from your browser or file manager when asked. |
| macOS | Not yet | Mac builds will be back once Apple signing is set up. |

Most PCs are x64. Pick arm64 for a Raspberry Pi or another ARM computer.

## Updates

The installed Windows version checks this repository for new releases and
updates itself. The update files (`latest.yml` and similar) live here for
that reason, so you don't need to download them yourself. The Microsoft
Store version updates through the Store.

## Something wrong?

Report bugs and ask for features in the
[main repository's issues](https://github.com/priyanshdas/inkleaf/issues).
Release notes for each version are on its release page here.
